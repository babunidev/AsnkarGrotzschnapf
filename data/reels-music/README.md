# Reels music library

Drop commercially licensed instrumental tracks here once. Anskar picks one file at random for each compilation Reel (repeats are fine) and mixes it with FFmpeg.

Supported extensions (top level only): `.mp3`, `.ogg`, `.wav`, `.m4a`, `.aac`, `.flac`.

Do not leave MIDI (`.mid`), MuseScore (`.mscz`), or project folders here — only the finished audio files.

If this folder has no supported audio, the Reel still publishes with a silent AAC audio stream (48 kHz stereo). Music failure never blocks publish.

Binary audio files are gitignored. Keep license proof outside the repository (or beside your purchase receipt).
